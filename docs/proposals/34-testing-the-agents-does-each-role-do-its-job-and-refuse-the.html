Options

A · Static onlyL0 L1 L5 · free · every commit

Catches drift and a missing pin. Says nothing about behaviour.

B · + routing+ L2 · one call a night

Catches the wrong role being picked. Still blind once it runs.

C · The gym+ L3 L4 · 8 runs on change

The only one that catches a test-engineer that patches code.

Recommended: C, in order A → B → C. A is free and is the only layer that can gate every commit; build the expensive layer last.
