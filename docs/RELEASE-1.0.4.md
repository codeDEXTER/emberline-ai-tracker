# common-rules 1.0.4

Patch release for tracker readability.

## Included

- Proposal scope controls are placed with the filters.
- The primary reading flow is now proposal tree, priority queue, progress
  history, then details.
- “By urgency” is renamed “Priority queue” with an inline explanation.

## Verification

The PhotoVault tracker was regenerated and inspected in the browser. The
accessibility order and rendered layout both follow the new reading flow.
