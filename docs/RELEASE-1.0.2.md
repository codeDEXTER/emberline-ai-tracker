# common-rules 1.0.2

Patch release for the shared workflow standard.

## Included

- Explicitly states that the standard is consumed by both Claude Code and
  Codex.
- Defines the rules as consumer-neutral across ledgers, trackers, handoffs,
  verification, and safety.
- Records the PhotoVault tracker-template visual review and confirms the
  existing P30/P-14 fixes in the regenerated tracker.

## Compatibility

This release does not add a mandatory adoption step or change the ledger
contract. It clarifies how the existing contract applies across the two
consumers.
